## Item-purification procedure

1. Run PLS algorithm; inspect outer loadings.
2. If any loading < 0.70, drop the item with the lowest loading and re-run.
3. Repeat until all loadings ≥ 0.70 (8 runs in total).
4. Check Cronbach's α and CR ≥ 0.70, AVE ≥ 0.50.
5. Check discriminant validity with HTMT (< 0.90; Henseler et al., 2015).
6. Check collinearity (VIF < 3), R², f², and bootstrapped significance of paths.

| Criterion | Threshold | Source |

## Group comparisons (n = 300)

Levene's test was significant for all three groupings (age p = .032, income p = .010, gender p = .037), so Welch's robust test is the reference result.
Only gender is significant (Welch F = 12.508, p = .001; female mean ≈ 5.7 vs male ≈ 5.3 on the 7-point scale).
